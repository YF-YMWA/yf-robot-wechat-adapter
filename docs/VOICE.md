# 发语音条（按住 Alt）

微信 PC 支持「按住 Alt 说话」。适配器利用这一点，把**合成的语音**送进微信麦克风，
松开 Alt 就发出一条真正的语音条（不是音频文件）。

---

## 先决条件：声音要能进微信的麦克风

微信录音录的是**麦克风设备**，不是系统声音。所以要让合成语音被录到，必须有一条"声学回路"。
三种做法，从好到差：

### 方案 A：虚拟声卡（推荐，音质无损）

1. 装 [VB-CABLE](https://vb-audio.com/Cable/)（免费），装完会出现
   `CABLE Input`（播放端）和 `CABLE Output`（录音端）
2. 微信 → 设置 → 语音与视频 → 麦克风：选 **CABLE Output**
3. 适配器配置里把播放设备指向 **CABLE Input**

### 方案 B：系统「立体声混音」

1. 声音设置 → 录制 → 右键显示禁用设备 → 启用 **立体声混音**
2. 微信麦克风选 **立体声混音**
3. 适配器播到 **扬声器**（你现在用的那个）

### 方案 C：外放（最省事，音质最差）

不需要额外设置：声音从扬声器放出来，微信用麦克风录进去。
缺点：环境噪音一起录进去，音质差；你也会听到它"自言自语"。

## 配置

`config.json`（适配器目录里）：

```json
{
  "wechat": {
    "voiceMode": "ptt",
    "voiceOutDevice": -1
  }
}
```

| 字段 | 说明 |
|---|---|
| `voiceMode` | `"file"` = 当文件发（默认，最稳）；`"ptt"` = 发真语音条 |
| `voiceOutDevice` | 播到哪个播放设备序号；`-1` = 系统默认。序号用下面的自检看 |

---

## 自检（不发消息）

双击 `语音自检.bat`，或在适配器目录执行：

```bat
runtime\python\python.exe voice_ptt.py
```

会打印：

- 微信窗口有没有找到
- 所有**播放设备**（带序号）
- 所有**录音设备**（微信麦克风应该是其中一条）
- 有没有虚拟声卡

想确认「这条线路微信能不能听到」，执行：

```bat
runtime\python\python.exe check_loopback_matrix.py
```

它会播一段 440Hz 音，同时录各个麦克风，报出哪一组「播放 → 录音」是通的
（`✅ 通` 表示微信用这条麦克风时能听到）。

## 试发一条（只在微信里操作）

```bat
runtime\python\python.exe voice_send.py "你好，这是一条测试语音" 文件传输助手 1
```

参数：文字、聊天名、播放设备序号。
默认发到「文件传输助手」（发给自己），不会打扰别人。

## 已知限制

- **需要前台**：按住 Alt 必须作用在微信窗口上，所以发送瞬间微信会被拉到前台
  （和现有发送逻辑一致，发完不影响别的）
- **时长下限**：微信判断「说话时间太短」不发，适配器强制至少按住 1.2 秒
- **环境抢焦点**：如果你正在全屏游戏/远程桌面，可能按到别的窗口 ——
  适配器会检查前台是不是微信，不是就拒绝按键（不盲按）
- **失败自动回退**：发语音条失败会自动改发音频文件，回复不会丢

## 常见问题

### 「控件树拿不到」「落点窗口不属于微信」「打不开聊天」

日志里出现这些，说明 wechatauto 拿不到微信的 UIA 控件树，常见原因有两个：

1. **用管理员运行的** —— 微信不是管理员，两边完整性级别不一致就控制不了。
   直接双击运行即可（弹 UAC 点「否」）。
2. **安全软件拦了模块枚举 / 进程读取** —— 把 `python.exe` 和微信目录都加进白名单。

自检里会打印：

```
本程序是管理员运行: 否
微信是管理员运行: 查不到
```

「查不到」通常是第二个原因。修好之前：
- 切聊天会失败 → 先手动打开目标聊天，然后把聊天名留空（发到当前会话）
- 发完读不到消息 → 只说明「已按住 Alt 发送」，无法确认是不是语音条，你自己在微信里看一眼

### 发出去了但对方听不到声音

麦克风线路没通。跑 `语音自检.bat` 的第二段（线路测试），
看哪一组「播放 → 录音」显示 `[OK] 通`，然后把 `voiceOutDevice` 设成那个播放设备序号。

## 加杀毒软件白名单（解决「控件树拿不到」）

适配器要读微信进程的模块、给窗口发按键。部分安全软件会拦这些操作，
表现就是日志里「控件树拿不到」「落点窗口不属于微信」「打不开聊天」。

### 一键版

双击 `加入杀软白名单.bat` → UAC 点「是」。它会：

1. 自动找微信安装目录（进程 / 注册表 / 常见位置三重探测）
2. 把下面这些加进 Windows Defender 排除项
3. 如果装了第三方安全软件，打印该去哪儿加（Defender 会被第三方接管，加了也不生效）

结果写进 `av-whitelist.log`，可以直接看。

### 要加白名单的路径（手动时照抄）

```
C:\Users\<你>\Documents\deepseek-harness\default-workspace\YF-Robot
C:\Users\<你>\Documents\deepseek-harness\default-workspace\YF-Robot\runtime\python\python.exe
C:\Users\<你>\Documents\deepseek-harness\default-workspace\yf-robot-wechat-adapter
C:\Program Files\Tencent\Weixin
C:\Users\<你>\Documents\WeChat Files
```

### 第三方安全软件在哪加

| 软件 | 位置 |
|---|---|
| Reason Cybersecurity | 客户端 → 设置/Settings → 排除项 Exclusions → 添加文件夹 |
| 360 安全卫士 | 木马查杀 → 信任区 → 添加目录 |
| 火绒 | 防护中心 → 信任区 → 添加目录 |
| 腾讯电脑管家 | 设置 → 白名单 → 添加目录 |

加完重启适配器（关窗口 → 双击 `启动桥接.bat`），再跑 `语音自检.bat` 看警告是否消失。
